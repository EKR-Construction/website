# Images Directory

This directory contains images used throughout the website.

## Hero Background Image

**File**: `hero-background.png` or `hero-background.jpg`
**Usage**: Hero section background
**Recommended Size**: 1920x1080px or larger
**Format**: PNG or JPEG (optimized for web)

Upload your hero background image to this directory with the filename `hero-background.png` or `hero-background.jpg`.

## Team Member Images

**File Pattern**: `team-{name}.jpg`
**Usage**: Team member profile cards
**Recommended Size**: 800x600px (4:3 aspect ratio)
**Format**: JPEG (optimized for web)
